# Bryan Huntley Cello website

A responsive, one-page wedding and event cello website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and structure
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation and email inquiry form

## Preview on your Mac
1. Download and unzip the project.
2. Open the `bryan-huntley-cello` folder.
3. Double-click `index.html` to preview it in your browser.

The Google Fonts used by the page require an internet connection. The page otherwise works as a static site.

## Publish with GitHub Pages
1. Sign in at https://github.com.
2. Create a **public** repository named `bryan-huntley-cello` (or use a repository you already created).
3. Open the repository and choose **Add file → Upload files**.
4. Upload `index.html`, `styles.css`, and `script.js` from this folder. Upload the files themselves to the repository's top level, not an extra nested folder.
5. Commit the changes.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Choose branch **main** and folder **/(root)**, then click **Save**.
9. Wait a few minutes. GitHub will show your published URL in the Pages section. It will usually look like `https://YOUR-USERNAME.github.io/bryan-huntley-cello/`.

## Before sharing publicly
- Replace the designed hero artwork / portrait placeholder with real performance or cello photos you have permission to use.
- Add audio/video samples when ready.
- Check your email and phone number carefully.
- Test the contact form on a device with an email app configured. The form opens a prefilled email; it does not store or send submissions by itself.
- Consider adding a custom domain later. Do not purchase one until you have checked availability and pricing.

## Updating the website
Edit a file locally, then upload the changed file to the same repository path and commit the change. GitHub Pages republishes automatically after the commit.
